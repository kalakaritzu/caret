Everything you need. Nothing you don't.

Split View

Drag any tab onto another to open them side by side. Drop a file from the sidebar into a pane. Works with the terminal too.

Built-in Terminal

Open a PowerShell tab alongside your code. Full xterm.js rendering, font synced with the editor, smooth animated caret.

30+ Languages

Syntax highlighting for JavaScript, TypeScript, Python, Rust, Go, C/C++, HTML, CSS, SQL, YAML, and more via CodeMirror 5.

File Explorer

Open a folder in the sidebar, browse files, create and rename items, and drag them straight into any editor pane.

Find & Replace

Regex, whole word, case-sensitive search with live match count and inline replace — all in a compact floating bar.

Zen Mode

Press F11 to hide everything but the code. Smooth full-screen transition, toast hint on enter, Escape to return.

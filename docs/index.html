Features

Split panes

Drag any tab onto another to open them side by side. Drop a file from the sidebar directly into a pane. Works with terminals too.

Built-in terminal

Open PowerShell or cmd in a tab alongside your code. Full xterm.js rendering with horizontal scroll when word wrap is off.

Syntax highlighting

CodeMirror 5 highlighting for JavaScript, TypeScript, Python, Rust, Go, C, C++, HTML, CSS, JSON, YAML, SQL, Markdown, and more.

File tree

Open any folder in the sidebar. Create, rename, and delete files. Drag files from the tree straight into any editor pane.

Find & replace

Ctrl+F to search, Ctrl+H to replace. Supports regex, whole-word, and case-sensitive modes with a live match count.

Zen mode

Press F11 to hide the sidebar, tabs, and title bar. Press Escape to return. Useful for writing and focused sessions.
